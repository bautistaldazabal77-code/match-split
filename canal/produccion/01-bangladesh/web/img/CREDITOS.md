# Créditos de las fotos

Todas tienen licencias libres que permiten el uso comercial (CC0, CC BY o CC BY-SA). Vienen de Wikimedia Commons y Flickr, buscadas con la API de Openverse.
Las que tienen licencia CC BY o CC BY-SA exigen nombrar al autor y la licencia: **hay que copiar la lista de abajo en la descripción del video.** En pantalla, cada foto ya lleva su crédito corto.

Las fotos se recortaron, se movieron con zoom y se les bajó el color. Las marcadas como *ilustrativa* no muestran el lugar exacto de la historia, y así lo aclara el video cuando hace falta.
